# Failure reference

| Symptom | Meaning | Action |
|---|---|---|
| `No module named andy` | Package not on import path | Install editable or set `PYTHONPATH=src` |
| Missing fixture path | Command run outside repository root | Change to checkout root |
| `replay-miss` | Input absent from admitted fixture set | Use an exact fixture input |
| Duplicate input error | Normalized fixture keys collide | Assign one canonical record |
| Empty artifact URI | Parameters are not distributed here | Follow restricted artifact review |
| Closed session rejects a turn | Host closure is final | Start a new session ID |

Do not repair unexplained behavior by deleting the trace.
