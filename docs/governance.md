# Review authority

Maintainers own source changes. Operators own session initiation and termination. Reviewers own evidence labels. Artifact custodians own parameter distribution. None of these roles is delegated by model output.

A source release does not release a checkpoint. A passing contract suite does not close a behavioral finding. A closed finding does not establish a theory of the system.

Exceptions require a written decision with scope, expiration, and a named owner. Silence is not approval.
