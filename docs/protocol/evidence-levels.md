# Evidence levels

| Level | Example | Permitted conclusion |
|---|---|---|
| E0 | A model says it remembers | It produced a memory claim |
| E1 | The transcript contains the cited detail | The detail was in visible context |
| E2 | Retrieval and context manifests agree | The admitted path supplied the detail |
| E3 | Independent reconstruction reproduces the trace | The path is reproducible |

Do not elevate E0 to E2 because the output sounds specific. Do not lower E2 because the explanation sounds strange. The ledger and the prose answer different questions.
