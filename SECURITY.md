# Security and boundary reports

Do not include credentials, private transcripts, or parameter fragments in an issue. Report through the repository’s private security advisory channel when enabled; otherwise contact a repository administrator privately.

Include the commit, profile, minimal reproduction, and whether any external adapter was attached. Stop affected runs when host authority, evidence admission, or trace integrity is uncertain.

Supported review line: `0.9.x`. Earlier snapshots are retained for research provenance and receive no operational fixes. See [the threat model](security/threat-model.md).
