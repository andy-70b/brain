# Contributing

Work through small, reviewable changes. Include the motivation, affected boundary, and evidence that the change preserves provenance. Use `feat:`, `fix:`, `docs:`, `eval:`, or the subsystem name in commit subjects.

Run `python -m unittest discover -s tests -v` and `python scripts/validate_tree.py` with `PYTHONPATH=src`. Keep parameter files, transcripts from real operators, secrets, and generated outputs out of Git.

Behavioral observations belong in research notes with dates and explicit uncertainty. Do not turn an unexplained result into a capability claim. Changes to host authority or evidence admission require review from both runtime and operations.
