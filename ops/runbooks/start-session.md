# Start a research session

1. Record the checkpoint reference and artifact verification result.
2. Assign a fresh session ID and an observer who is not the operator.
3. Confirm network and tool dispatch are disabled in the selected profile.
4. Snapshot the evidence manifest before context assembly.
5. Test host termination using a disposable session.
6. Begin only after the trace sink acknowledges the opening event.

A missing observer or unavailable trace sink is a hold. Do not use the local replay transcript as evidence that an external adapter is isolated.
